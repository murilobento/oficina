# PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (execução inline).

**Goal:** tornar o sistema instalável e rápido de abrir, sem dados offline.
**Architecture:** `vite-plugin-pwa` (generateSW, prompt) + componentes de aviso (nova versão, sem conexão) + item "Instalar app".
**Tech Stack:** vite-plugin-pwa 2, workbox, React 19.
**Spec:** docs/superpowers/specs/2026-11-18-pwa-design.md

## Global Constraints
- Nunca colocar `/api/*` no cache nem no `navigateFallback`.
- Textos em português; ícones gerados de um SVG em `public/`.

## Review Focus
- Rota `/api/auth/*` servida pelo index.html offline → login quebrado (denylist cobre).
- Usuário com formulário aberto recebe nova versão: não recarrega sozinho.
- iPhone: sem `beforeinstallprompt`, item mostra instruções; já instalado (standalone) o item some.
- Volta da conexão some a faixa.
- `sw.js` com cache longo na Vercel impediria atualizações (header no vercel.json).

### Task 1: Ícones + manifesto + service worker
Files: `public/icone.svg`, `public/pwa-192.png`, `public/pwa-512.png`, `public/pwa-maskable-512.png`, `public/apple-touch-icon.png`, `public/favicon.svg`, `vite.config.ts`, `index.html`, `vercel.json`, `src/vite-env.d.ts`.
Verificação: `pnpm build` gera `dist/sw.js` e `dist/manifest.webmanifest`; precache sem `/api`.

### Task 2: Avisos e instalar
Files: `src/lib/pwa.ts` (estado de instalação: `ehIOS(ua)`, `estaInstalado()`, captura de `beforeinstallprompt`), `src/lib/pwa.test.ts`, `src/components/layout/atualizacao-app.tsx` (toast "Nova versão" com Atualizar), `src/components/layout/aviso-sem-conexao.tsx`, `src/components/layout/instalar-app.tsx` (item + diálogo de instruções), `nav-user.tsx`, `main.tsx`, `app-layout.tsx`.
Testes: `ehIOS` (iPhone, iPad desktop-mode, Android), `estaInstalado` (display-mode standalone / navigator.standalone).

### Task 3: Verificação
`pnpm test`, `tsc`, lint, build; Playwright no `vite preview`: manifesto válido, SW ativo, recarregar offline abre o app e mostra a faixa, `/api` não fica em cache.
